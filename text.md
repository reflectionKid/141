## Основы редактирования текста

### Курсор

Клавиши и клавиатурные сокращения

- `Home` - курсор в начало строки
- `END` - курсор в конец строки
- `pgUP` - курсор вверх видимой части документа
- `pgDown` - курсор вниз видимой части документа
- `Del` / `Delete` - удаление символа справа от курсора
- `Backspace` - удаление символа слева от курсора
- `^` / `v` - перемещение курсора вверх и вниз
- `Ctrl+>` / `Ctrl+<` - перемещение курсора вправо и влево по словам
- `<` / `>` - перемещение курсора влево и вправо по символам
- `INS` `Insert` - режим замены, замещает старый текст новым справым от курсора
- `Tab` - отступ на 2 или 4 пробела
- `Esc` - отмена текущего режима

### Текст

#### Редактирование

- `CapsLock` - все строчные буквы (верний регистр)

#### Выделения

- `Ctrl+A` - выделить весь текст
- `Shift+>` - посимвольное выделение вправо
- `Shift+<` - посимвольное выделение влево
- `Ctrl+>` - пословное выделение вправо
- `Ctrl+<` - пословное выделение влево
- `Ctrl+V` - вставка скопированного
- `Ctrl+C` - копирование выделеного
- `Ctrl+Shift+C` - копирование выделенного в терминале
- `Ctrl+Shift+V` - вставка выделенного в терминале
- `Ctrl+X` - вырезать выделенное

#### Сохранение и отмена

- `Ctrl+S` - сохранить текущий документ
- `Ctrl+Z` - отменить изменение
- `Ctrl+Y` - к последнему изменению (отмена отмены)

#### Поиск по документу

- `Ctrl+F` / `F3` - поиск
- `Ctrl+H` - поиск с заменой

### Папки
Переместить файл
```shell
mv more_file.txt newDir/
```
Зайти в указанную папку
```shell
cd newDir
```
Выйти из текущей папки
```shell
cd ..
```
Вернуться в предыдущую папку
```shell
cd -
```
Удалить указанную папку
```shell
rm -rf newDir
```
