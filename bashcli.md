# Основы Bash CLI

**Bash** - терминал, командная строка, консоль. Ещё **Bash** - это скриптовый ЯП

файл `bashcli.md`

### Терминал

Сдвинуть вверх лог выполненных ранее команд
```shell
Ctrl+L
```
Очистить весь экран терминала
```shell
clear
```
Сбросить терминал
```shell
reset
```
Получить историю всех ранее введённых команд
```shell
history
```
Прервать выполняемый процесс
```shell
du /
```
Выполнить команду по её порядковому номеру
```shell
!23
```
Выполнить последнюю команду из списка `history`
```shell
!!
```
Перелистывать ранее введенные команды
```shell
Стрелки вверх/вниз ^v
```
Выйти из текущего терминнала
```shell
exit
```
Дописывание команд и имён файлов/каталогов
```shell
Tab
```

## Linux

Получить информацию по дистрибутиву
```shell
lsb_realese -a
```
или красивей
```shell
fastfetch
```
или технические подробности
```shell
inxi -F
```
Системный монитор
```shell
htop
```
`Q` - выйти из `htop`
Получить имена текущих пользователей
```shell
w
```
Получить состояние оперативной памяти и подкачки
```shell
free -h
```
Получить список групп, в которых числятся текущие пользователи
```shell
groups
```

## Софт

Показать календарь
```shell
cal
```
Показать дату и время
```shell
date
```
Получить содержимое текстового файла
```shell
cat имя_файла
```
Отредактировать текстовый файл
```shell
nano имя_файла
```
Сохранить `Ctrl+S`, выйти `Ctrl+X`

## Сеть

Получить имя компьютера
```shell
hostname -i
```
Информация по сети
```shell
ifcongig
```
или
```shell
ip -c r
```
Пинг адреса
```shell
ping 8.8.8.8
```
```shell
ping ya.ru
```
Чтобы выйти из бесконечного пинга, выполните `Ctrl+C`
Выполнить пинг указанное количество раз
```shell
ping -c 4 ya.ru
```
Получить информацию по указанному домену
```shell
whois ozon.ru
```
Получить список портов
```shell
netstat -an
```
Получить маршруты
```shell
route
```
## Управление компьютером

Перезагрузка
```shell
reboot
```
или
```shell
sudo shutdown -r now
```
или
```shell
sudo systemctl reboot
```
Выключение
```shell
poweroff
```
или
```shell
sudo shutdown -p now
```
или
```shell
sudo systemctl poweroff
```

## Файловые операции

Получить абсолютный путь к текущей директории
```shell
pwd
```
Получить содержимое текущей директории
```shell
ls
```
