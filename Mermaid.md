## Mermaid

**Mermaid** - это сильно упрощённый и далёкий аналог **UML** - специальный язык описани блок-схем, графиков и диаграмм с их визуализацией.

> **Самсостоятельно доделать это ридми**

### Блок схемы

#### Базовая структура 1
```mermaid
flowchart LR
    A[Вопрос: Как сделать список?] --> B["Ответ: `-` или `*`"]
    A --> C["Пример: \n - Пункт 1 \n"]
```
* `flowchart` - блок-схема
* `LR` - направление вправо
* `A[],B[],C[]` - прямоугольник
* --> - стрелка связи

Виды Mermaid-диаграмм
- Блок-схемы - `graph`, `flowchart`
- Последовательности - `sequenceDiagram`
- Классы - `classDiagram`
- Диаграмма Ганта - `gant`
- Круговые - `pie`
- Состояния
- ER-диаграммы
- Графы зависимостей


## Блок-схемы
Блок-схема показывает последовательность действий или алгоритм.

```mermaid
flowchart TD
    A[Начало] --> B[Ввод данных]
    B --> C{Данные корректны?}

    C -->|Да| D[Обработка данных]
    C -->|Нет| E[Ошибка]

    E --> B
    D --> F[Вывод результата]
    F --> G[Конец]
```

## Диаграмма последовательности

Показывает взаимодействие между несколькими объектами или участниками во времени.

```mermaid
sequenceDiagram
    participant U as Пользователь
    participant S as Сервер
    participant DB as База данных

    U->>S: Отправляет запрос
    S->>DB: Запрашивает данные
    DB-->>S: Возвращает данные
    S-->>U: Отправляет результат
```

## Диаграмма класса

Используется для представления классов, их свойств, методов и связей.

```mermaid
classDiagram
    class User {
        +String name
        +String email
        +login()
        +logout()
    }

    class Admin {
        +deleteUser()
        +banUser()
    }

    class Product {
        +String name
        +float price
        +getInfo()
    }

    User <|-- Admin
    User --> Product
```

## Диаграмма Ганта

Используется для отображения задач и сроков выполнения проекта.

```mermaid
gantt
    title План разработки проекта
    dateFormat YYYY-MM-DD

    section Анализ
    Сбор требований :a1, 2026-09-01, 3d
    Анализ требований :a2, after a1, 4d

    section Разработка
    Создание проекта :a3, after a2, 2d
    Программирование :a4, after a3, 7d

    section Тестирование
    Тестирование :a5, after a4, 4d
    Исправление ошибок :a6, after a5, 3d
```

## Граф зависимостей

Граф зависимостей показывает, какие компоненты, модули или элементы зависят друг от друга.

```mermaid
flowchart TD
    A[main.py] --> B[config.py]
    A --> C[database.py]
    A --> D[api.py]

    D --> C
    D --> E[models.py]
    C --> E
```

## Диаграмма состояний

Показывает различные состояния объекта и переходы между ними.

stateDiagram-v2
    [*] --> Ожидание
    Ожидание --> Обработка: Получен запрос
    Обработка --> Успешно: Успех
    Обработка --> Ошибка: Ошибка
    Ошибка --> Ожидание: Повторить
    Успешно --> [*]

## User Journey

Показывает путь пользователя через различные этапы взаимодействия с системой.

```mermaid
journey
    title Путь пользователя при покупке товара
    section Поиск
        Открывает сайт: 5: Пользователь
        Ищет товар: 4: Пользователь
        Просматривает результаты: 4: Пользователь
    section Покупка
        Открывает товар: 5: Пользователь
        Добавляет в корзину: 5: Пользователь
        Оформляет заказ: 3: Пользователь
    section Получение
        Получает уведомление: 4: Пользователь
        Получает товар: 5: Пользователь
```

## Кастомизация стилей

Mermai позволяет изменять внешний вид отдельных элементов диаграммы с помощью `style`.

```mermaid
flowchart TD
    A[Начало] --> B[Обработка]
    B --> C{Успешно?}
    C -->|Да| D[Готово]
    C -->|Нет| E[Ошибка]

    style A fill:#90EE90,stroke:#006400,stroke-width:2px
    style B fill:#87CEEB,stroke:#00008B,stroke-width:2px
    style D fill:#90EE90,stroke:#006400,stroke-width:2px
    style E fill:#FFB6C1,stroke:#8B0000,stroke-width:2px
```

## Классы CSS

Для нескольких элементов можно создать собственный стиль с помощью `classDef`.

```mermaid
flowchart LR
    A[Пользователь] --> B[Система]
    B --> C[Успех]
    B --> D[Ошибка]

    classDef user fill:#DDEEFF,stroke:#336699,stroke-width:2px
    classDef success fill:#DDFFDD,stroke:#339933,stroke-width:2px
    classDef error fill:#FFDDDD,stroke:#CC3333,stroke-width:2px

    class A user
    class C success
    class D error
```

## Интерактивность

Mermaid позволяет добавлять действия при нажатии на элементы диаграммы с помощью `click`.

```mermaid
flowchart TD
    A[Главная страница] --> B[Каталог]
    B --> C[Товар]
    C --> D[Корзина]

    click A "https://example.com"
    click B "https://example.com/catalog"
```
